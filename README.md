# One guide, six looks

A design study: the same phone prototype of an English restaurant guide for
first-time visitors to Beijing, drawn six different ways.

Open it: https://kuk1song.github.io/food-guide-looks/

- Design test only. The restaurant details are unchecked drafts; do not rely on them.
- The search and ordering helpers are scripted rules. No AI model is connected.
- No photographs. All imagery is hand-written SVG and CSS.
- Static files, no build step, no external requests.
